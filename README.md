# aqua-threads-images

Public image host for [@aqualux.studio](https://www.threads.com/@aqualux.studio) Threads posts.

The Threads Graph API needs a public `image_url` when publishing an image post. Only AI demo images meant for those posts belong here.

**Do not upload** private, confidential, or credential files, including Expansteel / 浤康 materials, tokens, or anything not intended for public posting.

## Layout

Files are stored as `YYYY-MM-DD/<slug>.<jpg|png>`.

Raw URL:

```
https://raw.githubusercontent.com/chengchiehhuang-glitch/aqua-threads-images/main/YYYY-MM-DD/<slug>.<ext>
```

Use `~/.threads-aqua/host_image.sh` on the box to copy, commit, push, and print a verified raw URL.
